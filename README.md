# Before Gods: Odysseus' Nostos

## Описание проекта

**Before Gods: Odysseus' Nostos** — 2D action-RPG с элементами roguelite и текстового квеста, где игрок управляет Одиссеем после падения Трои в эпоху краха бронзового мира (~1200 год до н.э.).

Игра сочетает:
- **Боевой экшен в 2D** — быстрые бои, акробатика, оружие (меч, копьё, лук, весло)
- **Текстовые события** — моральные выборы, торговля, дипломатия
- **Roguelite-цикл** — смерти влияют на мир, каждый забег открывает новые маршруты
- **Падение богов** — Divine Currency Status (DCS) симулирует упадок веры в богов
- **Управление командой** — корабль как хаб, система доверия, ресурсы

## Философия игры

> Одиссей пытается вернуться домой, но мир, из которого он вышел, уже умирает. Главный вопрос не «как выжить?», а «кем станет герой к моменту возвращения?»

## Ключевые идеи

### 1. **Морской контроль**
Одиссей должен вернуться домой, но:
- Посейдон его проклял (море враждебно)
- Нужно собрать ресурсы и команду
- Каждый выбор влияет на финальное путешествие

### 2. **Падение богов**
- **DCS система:** боги буквально теряют силу по ходу игры
- Молитвы перестают работать
- Жертвы становятся бесполезны
- Люди перестают верить

### 3. **Хитрость против силы**
- Метис механика: Одиссей может победить ложью, а не мускулами
- Система ложных диалогов и скрытых путей
- Награды за умные решения, штрафы за раскрытие

### 4. **Roguelite с историей**
- Каждая смерть открывает новые маршруты
- Мир меняется с каждым прохождением
- Запоминание предыдущих попыток влияет на диалоги

### 5. **Корабль как второй герой**
- Не просто "хаб", а живой организм
- Команда имеет имена, личности, доверие
- Ресурсы на корабле ограничены
- Каждый выбор влияет на команду
