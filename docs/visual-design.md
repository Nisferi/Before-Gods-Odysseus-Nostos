# Before Gods: Odysseus' Nostos — Визуальный дизайн

## 1. Концепция стиля

**Cel-shading + векторная графика 2D**

Не реалистичная Древняя Греция. Не инди-арт с шумом. **Живой рисунок** — как если бы ожил древний сосуд или фреска, но с современной техникой Cel-shading.

```
Референсы:
- Bastion (изометрический вид, Cel-shading)
- The Rogue Prince of Persia (2D, слои, активная анимация)
- Hades (стильная 2D, жирные линии, контраст)
- Афинская чёрнофигурная керамика (реальный источник)
- Medieval art illuminations (плоские фигуры, слои глубины)
```

## 3. Техника Cel-shading в 2D

### 3.1. Жирные контуры

Все персонажи, враги, объекты имеют **чёрный контур** (outline) толщиной 2–4 пикселя.

```
Слой персонажа:
├─ Контур (чёрный, 4px, за фигурой)
├─ Базовый цвет (основной силуэт)
├─ Светлые детали (2–3 оттенка светлее)
└─ Блики света (самые светлые части)
```

**Пример: Одиссей в боку**
```
Фон: #0a0804
├─ Контур: #000000 (4px)
├─ Плащ: #1a0f08 (основной)
├─ Золотая пряжка: #c8961c (контур + цвет)
├─ Светлая часть плаща: #3a2815 (затенение Cel)
└─ Кожа: #c8b49a (максимально светлое)
```

### 3.2. Плоский дизайн с намёком на глубину

**Без перспективы:** персонажи стоят на одной линии (как в древней вазописи).

**Глубина через:**
- Размер (дальше = меньше)
- Вертикальное положение (выше = дальше)
- Непрозрачность (дальше = чуть полупрозрачнее)
- Слои фона (параллакс)

### 3.3. Анимация (кадр за кадром, Cel-стиль)

**Без плавного движения.** Ключевые позы:
- Удар: 3 кадра (подготовка → удар → отскок)
- Ходьба: 4 кадра
- Парирование: 2 кадра (блок → восстановление)

Переходы между кадрами **резкие, без интерполяции** (как в классической анимации).

## 6. Слои и композиция

### 6.1. Глубина сцены (параллакс)

```
Слой 5 (дальний фон): Небо, далёкие горы (100% непрозрачность, мало деталей)
  ↓
Слой 4: Земля/вода, средние скалы (95% непрозрачность)
  ↓
Слой 3: Локальные объекты (деревья, руины) (90% непрозрачность)
  ↓
Слой 2: Враги, NPC (100% непрозрачность, чёткие контуры)
  ↓
Слой 1 (передний): Одиссей, ближайшие объекты, эффекты (100% непрозрачность)
```

При движении камеры:
- Слой 5 движется медленнее (25% скорости Одиссея)
- Слой 4 движется на 50%
- Слои 3–1 движутся нормально

### 6.2. Вертикальная композиция

**Персонажи стоят на одной горизонтальной линии,** но:
- Дальние враги стоят выше на экране
- Ближние враги стоят ниже
- Размер врага определяется дистанцией (меньше = дальше)

## 8. Анимация (правила Cel-shading)

### 8.1. Принципы

1. **Дискретная анимация** — нет плавных переходов, только ключевые кадры
2. **Контур остаётся чёрным** — даже во время движения
3. **Смена оттенков (Cel-затенение)** — при изменении угла света
4. **Всё кадр за кадром** — как в классической hand-drawn анимации

### 8.2. Примеры анимаций

**Удар мечом (3 кадра):**
```
Кадр 1 (подготовка):
├─ Одиссей, меч поднят вверх
├─ Оттенок: светлый (свет сверху)
└─ Длительность: 0.15 сек

Кадр 2 (удар):
├─ Одиссей, меч в горизонтали
├─ Оттенок: средний (контрастный)
├─ Вспышка: жёлтая линия контакта
└─ Длительность: 0.1 сек

Кадр 3 (отскок):
├─ Одиссей, меч внизу
├─ Оттенок: тёмный (свет сзади)
└─ Длительность: 0.2 сек
```

**Ходьба (4 кадра):**
```
Кадр 1: Правая нога вперёд
Кадр 2: Обе ноги на одной линии
Кадр 3: Левая нога вперёд
Кадр 4: Обе ноги на одной линии (вернулось)
Цикл: 0.6 сек (медленный, величественный шаг Одиссея)
```

**Парирование (2 кадра):**
```
Кадр 1 (блок):
├─ Щит поднят
├─ Зелёная вспышка Афины
└─ Длительность: 0.1 сек

Кадр 2 (восстановление):
├─ Щит опущен
├─ Готовность к контр-удару
└─ Длительность: 0.15 сек
```

## 9. Особенности Cel-shading для 2D

### 9.1. Растеризация и контуры

Все контуры **рисуются поверх** основного цвета:

```css
/* Примерный CSS для Cel-эффекта в браузере */
.character {
  filter: drop-shadow(
    -2px 0 0 #000,
    2px 0 0 #000,
    0 -2px 0 #000,
    0 2px 0 #000
  );
}

/* Для более жирного контура можно использовать SVG filter */
<filter id="cel-outline">
  <feMorphology operator="dilate" radius="2" />
  <feFlood flood-color="#000" flood-opacity="1" />
  <feComposite in="SourceGraphic" operator="xor" />
</filter>
```

### 9.2. Растеризация текстур (необязательно)

Для сильного Cel-эффекта можно добавить **шум или пиксельный стиль**, но в нашем случае это избыточно. Достаточно жирных контуров и плоского дизайна.

### 9.3. Освещение (условное)

В 2D нет реального освещения, но можно имитировать:
- **Свет сверху:** светлые части в верхней половине фигуры
- **Свет спереди:** светлые части на переде
- **Контрастные тени:** резкие границы между светом и тенью (не градиенты)

## 11. Рекомендации по реализации

### 11.1. В Unity (если перейдём на нелинию)

- Использовать **Sprite Outline** шейдеры (есть готовые в Asset Store)
- Рисовать персонажей слоями (body → limbs → equipment → outline)
- Анимация через **Sprite Swapping** (дискретная смена кадров)
- Параллакс через разные камеры на разных Z-позициях

### 11.2. В браузере (текущий прототип)

- Использовать **SVG** для персонажей и врагов (векторная графика)
- CSS `filter: drop-shadow` для контуров
- Canvas 2D для анимации эффектов (огонь, волны)
- Ключевая анимация через CSS `@keyframes` (дискретная, не плавная)

### 11.3. В Blender/Aseprite

- Рисовать вручную в **Aseprite** (pixel art + Cel-shading фильтр)
- Экспортировать спрайты с прозрачностью
- Добавлять контуры в Aseprite `Image → Contour` или вручную

## 12. Финальный образ

**Before Gods** должна выглядеть как **ожившая древняя ваза** — с жирными чёрными контурами, плоским дизайном, резкими переходами цветов и намёком на глубину через размер и позицию.

**Не должна быть:**
- Реалистичной (нет тени и света, нет градиентов)
- Пиксельной (не pixel art)
- Мультяшной (не Disney)
- Минималистичной (жирные контуры, чёткие детали)

**Должна быть:**
- **Cel-shaded** (плоские области цвета с чёрными контурами)
- **Векторной** (математически точные линии и формы)
- **Выразительной** (жирная линия = сильное решение)
- **Исторической** (палитра и композиция из древней керамики)
