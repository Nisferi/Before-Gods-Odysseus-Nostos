## 3. Ресурсная система (исторически обоснованная, 1200 BCE)

### 3.1. Текущие ресурсы

| Ресурс | Код | Иконка | Историческая база | Применение |
|--------|-----|--------|-------------------|-----------|
| Провизия | `food` | 🌾 | Зерно, сушёная рыба, оливки | Выживание команды, жертвы богам |
| Золото | `gold` | 🪙 | Браслеты, слитки, кубки | Торговля, подкуп, жертвоприношения |
| Бронза | `bronze` | 🔩 | Слитки бронзы — главный металл эпохи | Оружие, торговля (обесценивается) |
| Смола | `pitch` | 🔥 | Смола для конопатки кораблей | Ремонт корабля (критичен) |
| Олово | `tin` | ⚰️ | Олово — редкость; с медью = бронза | Производство бронзы, торговля |

**Почему нет железа и серебра:**  
Железо в 1200 BCE ещё не стало рядовым металлом — оно редкое и ритуальное. Серебро было, но финансовой системы ещё нет. Торговля идёт через бронзу и натуральный обмен. Это историческая точность.

### 3.2. Начальные значения

```typescript
const initialResources: Resources = {
  food: 0, gold: 0, bronze: 5, pitch: 2, tin: 0,
}
```

**Критические пороги:**
- `food < 3` — команда начинает роптать (HUD показывает предупреждение)
- `pitch < 2` — корабль в опасном состоянии (планируется в v1.2)
- `tin > 0` — редкость, открывает особые варианты торговли

### 3.3. Метис — характеристика, не ресурс

**Метис (μῆτις)** — хитрость, ум, способность к обману — является **характеристикой Одиссея** (0–5 пипов), а не грузом. Это намеренное геймдизайнерское решение: хитрость нельзя купить, она накапливается через правильные решения.

Рост Метис:
- Умный выбор в диалоге: +1
- Обман без последствий: +1
- Решение через хитрость вместо силы: +1
- Босс убеждением/обманом: +1

## 6. Система событий (текстовый RPG-слой)

### 6.1. Типы событий

**Фиксированное событие (`isFixed: true`):**  
Всегда первое. Сейчас: «Пробуждение» — Одиссей на берегу Трои, 3 выбора (обыскать/молиться/собрать команду).

**Событие из пула (weighted random):**  
Остальные 5 событий разыгрываются случайно по весам:
- `weight: 3` — Три мёртвых царя, Храм Аполлона
- `weight: 2` — Дезертир, Финикийский торговец, Пещера провидца

**Событие, связанное с уровнем:**  
Каждый объект в GameCanvas имеет `eventId`. При нажатии E рядом — `triggerEventById()` открывает то же событие из пула, не случайное.

### 6.2. Пул событий Акта 1 (MVP)

| ID | Название | Ключевые выборы |
|----|---------|-----------------|
| `awakening_beach` | Пробуждение | обыскать / молиться / собрать команду |
| `three_dead_kings` | Три мёртвых царя | золото / олово / хлеб / похоронить / философия |
| `apollo_temple` | Храм Аполлона | ограбить / похоронить жрецов / жертва Афине / солгать команде |
| `deserter_encounter` | Ахейский дезертир | помочь / обойти / расспросить / нанять |
| `phoenician_trader` | Финикийский торговец | купить / обменять бронзу / торговаться (Метис) / ограбить |
| `cave_of_seer` | Пещера прорицателя | заплатить / потребовать / обменять на историю |

### 6.3. Структура выбора (Choice)

```typescript
interface Choice {
  id: string
  text: string              // краткая метка кнопки
  subtext?: string          // условие/эффект для игрока
  requiresMetis?: number    // блокировка если метис меньше
  requiresFood?: number     // блокировка если провизии меньше
  requiresGold?: number     // блокировка если золота меньше
  requiresFlag?: string     // блокировка по флагу
  effects: GameEffect       // что изменяется
  result: string            // нарративный текст после выбора
  tone?: 'brave' | 'cunning' | 'pious' | 'ruthless' | 'wise' | 'neutral'
}
```

### 6.4. Пример ветвления: «Три мёртвых царя»

**Контекст:** На берегу три тела царей. Золото, олово, хлеб.

| Выбор | Требование | Ресурсы | DCS | Доверие | Метис |
|-------|-----------|---------|-----|---------|-------|
| Взять золото | — | +2 золота | −5 | −10 | 0 |
| Взять олово | — | +1 олово | −2 | +5 | 0 |
| Взять хлеб | — | +2 еды | 0 | +15 | 0 |
| Похоронить всех | — | 0 | +10 | +10 | 0 |
| «Цари теперь те, у кого хлеб» | Метис 2+ | +2 еды | +5 | +20 | +1 |

Последний вариант — это и игровая механика (бонус), и нарратив: фраза станет поговоркой команды.

## 7. Боссы Акта 1

### 7.1. Тень Гектора (Shadow of Hector)

**Когда:** После исчерпания пула событий (автоматически).  
**Смысл:** Воплощение вины Одиссея. Боевой дух защитника Трои.

**Фаза 1: Бой (3 варианта)**
- Атаковать яростно — риск (−10/−15 HP), +слава, +гнев
- Парировать и контратаковать — надёжно (−5 HP), +благочестие
- Обмануть тень (Метис 2+) — минимальные потери (−3 HP), +Метис

**Фаза 2: Диалог (4 варианта)**
- Добить — +слава, +тень, −DCS
- Попросить прощения — +благочестие, +Афина, +Ностос
- «Троя была необходима» (Метис 1+) — +Метис, +слава (с ложью)
- Молча уйти — +Ностос, достоинство

### 7.2. Посланник Посейдона (Poseidon's Messenger)

**Когда:** Сразу после Тени Гектора (цепочка).  
**Смысл:** Первый контакт с проклятием. Море не отпускает.

**Фаза 1: Прибытие (3 варианта)**
- Принять бой — −20 HP, +слава; существо «насытилось» и уходит
- Жертва Посейдону (−3 еды, −2 золота) — снижает гнев Посейдона на 20, небольшой штраф Афине
- Бежать к кораблю — −30 HP, открывает «рискованный маршрут»

## 8. Система боссов → Финальный выбор → Конец Акта 1

```
Пул событий исчерпан
        ↓
[BOSS] Тень Гектора (2 фазы)
        ↓
[BOSS] Посланник Посейдона (1 фаза)
        ↓
[FINALE] Три варианта:
  А. Отплыть немедленно — риск (плохой исход если food<3 или trust<30)
  Б. Ритуал (−2 еды, −2 золота) → +15 Афина → победа
  В. Разговор с командой (требует trust≥50) → +15 trust → победа
        ↓
[VICTORY] или [DEATH]
```

**Условия исходов:**

| Исход | Условия | Что происходит |
|-------|---------|----------------|
| Хороший | food≥5, trust≥40, Афина≥20 | Отплытие в спокойное море, хороший старт Акта 2 |
| Нейтральный | food 3-4, trust 30-50 | Отплытие в шторм, трудный Акт 2 |
| Плохой | food<3 или trust<30 | Корабль разбивается, DCS −10, перезагрузка |
| Смерть в акте | HP=0 или trust=0 | Потеря половины ресурсов, DCS −5, новый путь открыт |

## 9. Roguelite-метапрогрессия

### 9.1. Что сохраняется между забегами

| Элемент | Сохраняется | Примечание |
|---------|------------|------------|
| DCS | Да (падает) | Каждая смерть −5, каждый плохой исход −10 |
| Глобальные флаги | Да | `poseidon_cursed`, `knows_curse_details` и др. |
| Разблокированные маршруты | Планируется (v1.5) | Новые локации после первого нахождения |
| Разблокированные события | Планируется (v1.5) | Редкие события после выполнения условий |
| Память NPC | Планируется (v2.0) | «Отголоски» предыдущей жизни — NPC упоминает прошлое |

### 9.2. Что НЕ сохраняется (сбрасывается каждый забег)

- Ресурсы (food, gold, bronze, pitch, tin) → стартуют с нуля
- HP Одиссея → 100
- Статы (Ностос, Слава, Гнев...) → исходные значения
- Команда → 5 стандартных членов, trust сбрасывается
- Завершённые события → пул обновляется

### 9.3. Глобальные флаги (сохраняются между актами и забегами)

| Флаг | Когда устанавливается | Влияние |
|------|----------------------|---------|
| `knows_curse_details` | Акт 1: посещение пещеры провидца | Дополнительные диалоги во всех актах |
| `lied_about_temple` | Акт 1: солгал команде о проклятии | Команда может узнать правду позже |
| `knows_prophet_cave` | Акт 1: дезертир рассказал о пещере | Подсказка маршрута |
| `poseidon_cursed` | Акт 4: назвал имя Полифему | Море постоянно враждебнее |
| `circe_ally` | Акт 7: год на острове Кирки | Кирка помогает при Некии |
| `elpenor_buried` | Акт 7: выполнил просьбу | Элпенор не мешает в Некии |
| `team_drank_lotus` | Акт 3: команда попробовала лотос | Члены команды иногда «мечтают» |
| `cattle_killed` | Акт 10: команда убила коров | Гелиос враждебен навсегда |

## 10. Все 14 актов: подробное описание

### 10.1. Акт 1 — После Трои (Берег Трои, Фракия)

**Историческая база:** 1184 BCE (по Эратосфену). Ахейская коалиция разбегается. Боги делят добычу.  
**Сюжет прототипа:** Одиссей просыпается на берегу. Посейдон уже проклял его (флэшбек — эпизод с Циклопом произошёл раньше). Афина ещё рядом. DCS: 85.

**Ключевые NPC:**
- Евриох (Eurylochus) — помощник капитана, скептик; trust 60
- Полит (Polites) — разведчик; trust 50
- Кир (Kyros) — гребец; trust 45
- Фемий (Aed) — певец-аэд; trust 55
- Лаэрк (Smith) — кузнец; trust 40
- Безымянный провидец в пещере (NPC, не член команды)
- Финикийский торговец (NPC, антагонист-союзник)
- Алексий — фракийский воин (Фракия, NPC-диалог)
- Артемиса — жрица Деметры (Фракия, NPC-диалог)

**Ключевое ветвление:**
- Немедленно → шторм (тяжёлый Акт 2)

- С максимальными ресурсами → лучший старт в Акт 2

### 10.2. Акт 2 — Исмарос (Киконы, Фракия)

**Историческая база:** Исмарос — реальный город в Фракии. Одиссей напал. Войска опьянели и были разгромлены. Потери: 72 человека (по Гомеру — 6 с каждого корабля, 12 кораблей).

**Ключевые NPC:** Марон — жрец Аполлона (дарит вино); вождь Киконов; выжившие ахейцы.

**Ключевые решения:**

| Запретить | −20 доверие | +безопасность |
| Взять только еду и уйти (Метис 3+) | +food, 0 потерь | +Афина, +Метис |

### 10.3. Акт 3 — Лотофаги

**Историческая база:** Жители едят цветок лотоса — забывают прошлое. Одиссей вытащил троих разведчиков силой.

**Ключевые NPC:** Старейшина Лотофагов; трое разведчиков (члены команды с флагом).

**Ключевые решения:**

| Решение | Эффект |
|---------|--------|
| Запретить есть | +Ностос, +доверие |
| Попробовать самому | +HP, −Ностос −20 |
| Подменить лотос (Метис 3+) | 0 потерь, команда не знает |

**Ключ:** Если Ностос < 20 к Акту 11 → открываются альтернативные финалы.

### 10.4. Акт 4 — Циклоп Полифем

**Историческая база:** Полифем, сын Посейдона. «Никто» — эталон хитрости в мировой литературе. Ослепление = постоянное проклятие моря.

**Ключевые NPC:** Полифем; трое пленников (члены команды).

**Три пути:**

**1. Метис (канонический):** Вино → пьяный Полифем → «Никто» → ослепление → побег → Одиссей назвал имя → флаг `poseidon_cursed` (permanent).

**2. Сила:** Тяжёлый бой без ослепления. Потери команды, но Посейдон не знает имя.

**3. Переговоры (Метис 4+):** Узнать о жизни Полифема → договориться о выходе в обмен на историю → Посейдон менее враждебен.

**DCS на выходе:** 55–65

### 10.5. Акт 5 — Эол и мешок ветров

**Историческая база:** Мешок с ветрами. Команда думала — золото. Открыла. Шторм. Возврат к Эолу — он отказал.

**Ключевые NPC:** Эол — владыка ветров; его 6 сыновей и 6 дочерей.

**Механика:** Защита мешка 3 цикла. Каждый цикл — риск, что команда откроет.

| Ситуация | Как снизить риск |
|----------|-----------------|
| Команда видит мешок | Убрать далеко от трюма |
| Любопытство | Объяснить правду (+доверие) |
| Жадность | Дать другую добычу взамен |

**Итог с высоким доверием:** Мешок цел → ускоренный переход.  
**Итог с низким доверием:** Шторм → возврат (Эол отказывает повторно).  
**DCS на выходе:** 50–60

### 10.6. Акт 6 — Лестригоны

**Историческая база:** Великаны-людоеды. Уничтожили почти весь флот Одиссея — спасся один корабль (его собственный, стоявший снаружи гавани).

**Ключевые NPC:** Царь Антифат; его жена-людоедка; дочь (подсадная утка).

**Механика:** Акт потерь. Нельзя выйти без потерь — только выбрать цену.

| Решение | Потери | Выгода |
|---------|--------|--------|
| Войти в гавань | −80% кораблей | Ничего |
| Остаться снаружи | −20% кораблей | Сохранить больше |
| Выманить в море (Метис 4+) | −10% кораблей | +Метис |

**После Лестригонов:** один корабль. Каждый выживший — уникальный ресурс.  
**DCS на выходе:** 45–55

### 10.7. Акт 7 — Кирка (Ээя)

**Историческая база:** Кирка (Цирцея) превратила команду в свиней. Одиссей с помощью травы молюй (Гермес) устоял. Год жизни на острове.

**Ключевые NPC:** Кирка — волшебница; Гермес (встреча); Элпенор (гибнет и станет важен в Акте 8).

**Три решения:**

1. **Как противостоять превращению?**
   - [Гермес] Трава молюй → иммунитет → переговоры
   - [Метис 3] Притвориться превращённым → разведка изнутри
   - [Сила] Атаковать Кирку → тяжёлый бой

2. **Сколько оставаться?**
   - Год → команда сильна для Некии, Кирка учит алхимии → флаг `circe_ally`
   - 3 месяца → базовое восстановление
   - Немедленно уйти → Ностос высок, команда слаба

3. **Дар Кирки:**
   - Алхимические зелья → боевой бонус
   - Информация о Подземном мире → нарративный бонус
   - Личный дар → зависит от решений

**DCS на выходе:** 40–50

**Ключевые NPC:** Тиресий, Мать (Антиклея), Агамемнон, Ахилл, Элпенор, Сизиф.

**Механика:** Каждый разговор требует жертвы крови (HP). Выбирай с кем говорить.

**После Некии:** параметр Тень становится активным — Одиссей видит мёртвых в живых актах.

   Ждать Гермеса → долго, безопасно

   Построить плот немедленно → Калипсо не даёт ветер, опасно

3. **Что взять?**  
   Знание Калипсо (алхимия+) → бонус в Акте 12

   Ничего → Ностос максимум

## 12. Визуальный стиль (реализованный)

### 12.1. Концепция

**Cel-shading + The Rogue Prince of Persia-inspired 2D**  
Не реалистичная Греция. Не пиксель-арт. Живой рисунок на Canvas — как если бы ожил чёрнофигурный греческий сосуд с современной техникой Cel-shading.

**Референсы:**
- The Rogue Prince of Persia — 2D платформер, слои, активная анимация
- Hades — жирные контуры, высокий контраст, стилизованные силуэты
- Bastion — ночная палитра, изометрический Cel-shading
- Афинская чёрнофигурная керамика — плоские фигуры, силуэты

### 12.2. Палитра (реализована в GameCanvas.tsx)

| Элемент | Цвет |
|---------|------|
| Небо (верх) | `#020101` |
| Небо (низ) | `#1c0805` |
| Море | `#050d18` |
| Земля | `#46300e` |
| Колонны | `#181008` с подсветкой `#2e2010` |
| Тело персонажа | `#0e0802` (тёмный) |
| Золото доспеха | `#c8961c` |
| Плащ | `#8b0000` (тёмно-красный) |
| Огонь | `#ff6600` / `#e02800` / `#ffaa00` |
| Портал | `rgba(120, 60, 180, ...)` пульсирующий |

### 12.3. Анимации (текущие)

- **Одиссей:** ходьба (маятник ног/рук с walkPhase), прыжок (физика), поворот (flip по X)
- **Огонь:** 3 слоя quadraticCurveTo с Math.sin фазами, glow через shadowBlur
- **Море:** 6 волновых линий со смещением по камере
- **Портал:** пульсация opacity + shadowBlur с Math.sin(time * 3)
- **Пещера:** пульсирующее фиолетовое свечение RadialGradient
